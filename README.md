# Ziyaretçi Defteri · Git Demo

İleri Web Programlama dersi "Git: GitHub / GitLab" sunumu için hazırlanmış küçük bir demo.

- `site/` – yayınlanan statik web sitesi (HTML + CSS + JS)
- `.github/workflows/pages.yml` – `main`'e her push'ta siteyi **GitHub Pages**'e yayınlar
- `.github/workflows/kontrol.yml` – her Pull Request'te basit kontroller çalıştırır
- `.gitlab-ci.yml` – aynı siteyi **GitLab Pages**'e yayınlar

## Yerelde çalıştırma

`site/index.html` dosyasını tarayıcıda açmak yeterli.
